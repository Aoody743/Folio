# 服务器浏览器

入口：**更多 → 运维 → 服务器浏览器**。启动后，网页由服务器上的 Chromium/Chrome 打开，面板显示实时画面并传递点击、滚动和键盘输入。客户端浏览器不直接请求目标网站，也不通过 iframe 加载网站。

访问使用服务器的 DNS 和网络出口；服务器本身已有代理、VPN 或 NAT 时，目标网站看到的是该出口地址。此功能不提供新的代理线路。

## 使用

- 点击启动，在地址栏输入 HTTP/HTTPS 地址，或输入关键词搜索。
- 使用标签页、前进、后退、刷新与停止控制网页；点击画面后可以使用键盘。使用“适应窗口”调整远端网页尺寸，全屏后也会适配可用空间。
- 网页提示、确认及文字询问会在画面上方显示，等待明确回复；新窗口链接在当前受控标签页打开。
- 手机或中文输入可通过文本发送框输入到网页当前获得焦点的字段；发送前先点击目标字段。
- 面板语言和主题可以继续切换；访问地址、输入内容和页面 Cookie 不存入面板 URL 或浏览器偏好。
- 关闭浏览器会结束远程进程并清理临时资料。短暂离开模块可以继续会话；闲置会话自动回收。服务器重启后需重新启动浏览器。

本版本用于交互访问网页，不提供远程文件上传、下载管理、音频或摄像头转发。网页声音、视频和动画的体验受截图传输频率及服务器资源影响。

## 服务器环境

需要 Linux 服务器已安装 Chromium 或 Google Chrome，且 Folio 服务用户可以在沙箱中启动它。面板会检查浏览器环境；没有可用引擎时会提示安装后重试。Folio 发行包不捆绑浏览器引擎，不会在后台自动安装系统软件。

请通过系统发行版或浏览器厂商的受信任来源安装。Debian 可使用系统的 `chromium` 软件包；Ubuntu 的 `chromium-browser` 可能是 Snap 启动器，部署前需确认它可由 systemd 中的 Folio 用户启动，或使用厂商提供的 Chrome Linux 软件包。Chromium 自身的系统依赖由对应软件包管理器维护。

生产安装器以 `powerlinux` 普通用户运行面板，保留现有 systemd 限制。浏览器不以 root 启动，不关闭沙箱，不忽略 HTTPS 证书错误，也不对外暴露 DevTools 调试端口。浏览器启动失败时应检查安装、用户命名空间及系统策略，界面会提供可查看的错误信息。

## 权限与接口

浏览器需要独立的 `browser:use` 权限与 `browser:server` 资源授权。此权限允许使用服务器可达的公网和内网网站，应授予允许使用这些网络能力的身份。管理员的完整权限包含该能力。会话按发起身份隔离，不能凭猜测会话标识读取其他身份的画面或输入。

动作通过现有 REST/MCP/Core 注册：环境状态、创建/关闭会话、列出/创建/关闭标签页、导航、历史、输入和调整视口。Cookie 写请求使用现有 CSRF 保护。截图只通过经过身份与权限检查的面板资源接口读取，并禁止缓存；DevTools 使用私有进程管道。

普通面板导航控制不使用持久化幂等响应缓存，也不自动重放不确定的输入。外部 REST/MCP 调用者若显式给返回会话信息的动作附加幂等键，仍遵循既有 Core 缓存语义，响应中的地址、标题可能保留在面板私有数据库中；不要将此功能视为保证抹除所有外部调用记录的匿名浏览器。

只允许 HTTP/HTTPS 网页和空白页，禁止 `file:`、`javascript:` 等地址作为导航目标。网页文本和访问地址不作为审计摘要保存。具体会话预算、租期及接口字段见源码公开的 capability schema；验收证据记录在当前 beta 的发行资产中。
