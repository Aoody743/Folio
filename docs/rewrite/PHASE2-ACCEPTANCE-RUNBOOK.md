# Folio 第二阶段验收执行表

本表用于 2026-10-17 起的首发验收。目标系统为 Debian 13 amd64 与 Ubuntu 24.04 amd64。勾选项必须附命令、日志或浏览器/MCP证据；源码测试和交叉编译不能替代原生验收。

## 1. 安装与恢复

- [ ] 干净主机安装候选包
- [ ] 重复运行安装器不覆盖受保护配置
- [ ] API、Agent、前端健康检查通过
- [ ] 服务重启后便签、任务、审计和软件 receipt 保留
- [ ] 升级保留数据和策略
- [ ] 失败升级可回退
- [ ] 卸载保留用户数据并清理自有服务

## 2. 网站与 PHP

- [ ] 首次选择 Nginx + PHP
- [ ] 首次选择 OpenResty + PHP
- [ ] 未选的 Web 栈不会安装或占用监听端口
- [ ] PHP 网站创建、访问、日志和停用
- [ ] 站点配置失败可恢复，文件默认保留
- [ ] 证书导入、绑定、HTTPS 本地检查
- [ ] 网站备份与独立目标恢复

## 3. MySQL 与 PostgreSQL

- [ ] 不选择数据库时不会安装数据库服务
- [ ] 只选择 MySQL 时安装、启动、建库和权限检查通过
- [ ] 只选择 PostgreSQL 时安装、启动、建库和权限检查通过
- [ ] 同时选择 MySQL 与 PostgreSQL 时按序安装且无包管理器竞态
- [ ] 数据库导入、备份、恢复和删除均绑定实例/数据库 revision
- [ ] 数据库凭据不出现在 UI、任务、审计或日志
- [ ] 网页与 MCP 的数据库权限允许/拒绝结果一致

## 4. 网页、MCP 与任务

- [ ] 同一动作在网页和 MCP 使用同一权限判断
- [ ] 未授权、撤权和资源越权均被拒绝
- [ ] 长任务有 queued/running/succeeded/failed 状态
- [ ] 取消、超时和重启恢复状态可解释
- [ ] 每项变更有审计记录和资源版本
- [ ] 便签网页编辑、MCP读取、AI修改、网页刷新和历史恢复闭环通过

## 5. 扩展能力

Next.js/Go 托管、Git/归档导入、数据库外部导入等属于可选扩展。扩展可以通过简单 UI 按需进入，但必须单独完成权限、任务、审计、失败恢复和原生环境验收；未完成前保持 `not_tested` 或 `in_progress`，不影响核心版范围判断。

## 6. 发布冻结

- [ ] 两个目标系统均有固定候选包和 SHA-256
- [ ] 构建来源、依赖和工作区状态已记录
- [ ] 安装、升级、回退和卸载说明与实际行为一致
- [ ] 记录响应时间、空闲 RSS 和系统修改基线
- [ ] 所有未完成项列入已知限制
- [ ] 只有本表必选项和四组退出检查全部有证据后，才将 `stage_2_complete` 改为 `true`
