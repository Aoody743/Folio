# UI 信息与操作重构

本轮保留“概览、网站、软件、文件、更多”底栏。按 2026-10-22 最新反馈，**手机允许自然下滑**；不再以手机主页面无纵向滚动作为验收门槛。桌面保持紧凑分页。顶栏手机只有“查看任务”，电脑额外保留账户入口；语言选择迁入“更多 → 语言与外观”。登录页仍可选择语言，方便首次登录。

## 导航与数据约定

- 使用静态发行兼容的 `#/section?…` 路由；浏览器返回、刷新、直接定位可恢复资源、分组、查询与分页。表单、密码、令牌、SQL、草稿不写入 URL。文件未保存时保护文件/目录切换，原有离开页面提示继续保留。
- 资源详情替换抽屉为独立内容页；内容仅有一个主要滚动区。底栏仍可导航，关闭详情后保留列表位置。后台已访问模块和草稿保持挂载，切换语言/字体不会重新创建表单。
- 主列表根据实际可用高度和行高分页；同一窗口宽度内保留测得的最大行高，避免长名称让分页来回跳变；已有网站/文件请求继续走服务端分页；完整返回的集合在客户端分页。错误不展示为零资源，未知状态不归为正常。
- `sites_list` 兼容增加 `status_counts: {running, stopped, unknown}`，在授权、查询、分类和可选状态筛选后，对分页前完整集合统计。新增可选 `status=running|stopped|unknown` 用于概览状态直达。原 items/total/limit/offset 不变。
- 网站 running 仅显示“已启用”，不代表公网健康；应用 running 需要运行探测与生命周期一致，冲突、过渡及缺失值进入“需检查”。
- `FontPreset = modern | native | reading`；所有字体本地提供并附 SIL OFL 1.1 授权。字体偏好 `folio.font`、语言 `folio.language`、配色既有键互不覆盖。

## 验证

必须覆盖：真实 API/MCP 文件与便签工作流、网站统计授权/筛选/分页、任务与计划历史、hash 直达/返回/刷新、草稿和幂等确认；中英 × 三套字体 × 五套配色；1366×768、1440×900、390×844、360×640、320×568；空集合、长名称、多页、无权限、执行器未配置、错误和状态未知。手机允许滚动和软键盘调整，保留正常字号与固定底栏。

本轮为 UI 与必要的兼容数据接口调整；不改安装器，不发布或覆盖已有 beta4 资产。实际执行记录和截图见 [本轮验收记录](UI-INFORMATION-ACCEPTANCE.md)。
