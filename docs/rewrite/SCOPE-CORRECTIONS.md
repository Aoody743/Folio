# 迁移清单的补充核对

阶段一验收期间进行了第二阶段只读预检。下面仅补足范围；没有将未实现功能标记为完成。

## 静态计数不能替代功能清点

原始清单235条HTTP路由、70个插件目录与1,358条动作字符串保留作为索引。23个核心插件的717条动作字符串不覆盖全部动态入口；257个跨插件去重名称也不等于257个独立能力。

- `plugins/data_query`除了index.py，还有`nosql_redis.py`、`nosql_memcached.py`、`nosql_mongodb.py`与`sql_mysql.py`。键类型、TTL、集合与文档、查询、进程/锁/死锁/索引/复制诊断必须逐项核实。页面通过`script=`动态分派，不能漏掉。
- `plugins/webssh`采用类方法动态分派；静态动作计数为0不代表无功能。SSH主机配置、密码/私钥/口令、已保存快捷命令均属于迁移范围。
- 本地与SSH终端还使用Socket.IO事件，不计入235条HTTP声明。新版以真实PTY与共享会话引擎实现，而不是向静态路由清单打勾。
- 文件操作不仅是列表、读取与写入，还包括编码、内容历史、尾部读取、分段上传、权限继承、覆盖预检、递归搜索、回收站，以及不同压缩格式的安全处理。

## 软件版本目录

实际脚本还声明PHP5.2、OpenResty1.29.2、PostgreSQL18与MariaDB12.1。PHP8.5/MySQL8.4脚本中的真实补丁版本与info.json更新数组并不完全一致。需分别核实来源、平台、可用性与验证条件；不能按数组位置组合版本。

Docker、Supervisor和rsyncd的旧集成版本号不是其软件版本，catalog分别记录两者。

## 证书提供商

核心界面13个DNS提供商与ACME插件32个提供商的并集为34个，加上手动解析。来源为旧核心证书页面与`plugins/acme_pandominassl_apply/js/common.js`。迁移范围覆盖并集，保留每个提供商的凭据字段、域名操作与验证条件。

协议验收可使用可信本地测试CA与实际ACME服务；真实DNS提供商签发则需要可用测试域名和受限凭据，缺失时记录外部验收阻塞。任何关闭TLS验证的旧选项均不能作为解决方案。

## 阶段依赖调整

第一阶段优先认证、状态、便签、任务、MCP和发行基础闭环。以下原本初分为第一阶段的条目移至第二阶段并保留：自定义登录入口／验证码、旧Webhook集成、应用授权的完整管理、面板名称／页脚／账户名称、临时登录链接与其日志。

当前Token基础提供权限、资源、有效期、委派与撤销；这不代表旧应用或临时登录页面已经完全迁移。状态快照已实现，但网站、计划任务、防火墙等聚合数量依赖第二阶段真实资源，不能提供伪造计数。

完整MySQL/MariaDB/PostgreSQL复制、SSH全量同步、Mongo复制集、PHP多来源与扩展、Docker导入导出和exec、rsync/lsyncd、FTP恢复及Supervisor进程配置均保留。通用安装／启停实现不够达到插件验收标准。
