## 第三批实现与验证

开发包 `1.0-beta7-ui-batch3`。没有发布新 beta，没有覆盖 beta7 安装器、资产或历史图库。

- 全局搜索延迟查询当前授权的网站/域名、应用、外部数据库、缓存和已安装实例；不具备能力的来源不查询，读取失败不显示成没有资源，结果支持资源直达与草稿导航保护。
- “更多 → 环境与维护”检查面板版本、就绪状态、执行器和浏览器组件，提供官方发行与升级说明；不自动启用权限或安装更新。
- 文件排序保留到路由；手机每页至少四项并允许下滑，桌面按高度分页；多选在预检后批量复制、移动或删除。覆盖需要明确确认和目标摘要，任务展示逐项结果。修复手机过滤控件叠放及跨模块遗留的高级动作列表。
- 多文件队列顺序上传，逐项 SHA-256 校验，失败暂停、续传跳过完成项；支持暂停、跳过、清空与重复名称检查。文件选择仅在本页面内存保留，刷新和退出会丢失，离开页面前有浏览器保护。每批最多 100 个文件。
- CPU/内存/磁盘告警支持持续时间、回落区间、通知间隔、授权重检和重启去重。默认停用；可以仅记录本地状态。通知使用已有渠道与任务，提交和实际送达严格区分。
- 网站和本机数据库分别保存资源绑定的保留策略。最新份数与保留天数同时保护；未知日期/摘要保留。清理需确认 15 分钟内的预览，实际任务逐项重新检查当前权限、策略、数量和摘要；变化项跳过，失败/撤销/取消停止并留下结果。保存策略不会自动删除，也未增加定时清理。
- 恢复记录使用当前可见的已授权任务；任务 API 新增兼容的 `action` 字段，避免数据库通用执行器遮蔽真实恢复动作。该记录不替代恢复演练或应用可用性验证。
- Firefox WASM 在入口检查安全上下文和 JSPI；面板浏览器提供本地常用地址，移除账号、查询参数及片段。明确临时会话和网页内文件传输限制；面板浏览器尚不支持网页内上传/下载，服务器文件仍使用文件页。
- 网站 TLS 详情改为绑定状态与证书入口，保留原有绑定操作；证书管理保持同一个标准页面及网站上下文。

验证：TypeScript、静态构建、101 项前端测试、全仓 Go 测试通过；Core/Systemops 并发检查通过。隔离浏览器验证实际告警新增/更新、保留策略保存、两文件上传中断继续、两文件批量复制；清理界面提交拦截，未删除主机备份。后端模拟受控备份源验证实际持久任务、保留规则、变化跳过、预览过期/重放和途中撤权，数据库来源也验证原生格式和资源隔离。

功能提交：`a21f8e7`。更多[第三批实际界面记录](../screenshots/ui-polish-batch3/README.md)。

新增测试：`test_resource_tools_browser.py`、`test_safety_tools_browser.py`、`internal/systemops/alerts_test.go`、`retention_test.go`、`frontend/tests/browser-usability.test.mjs`。只读展示夹具不作为真实主机生命周期证据。
