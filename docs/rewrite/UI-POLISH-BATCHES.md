# UI 与产品完善分批实施

2026-10-23。依据 beta7 产品审计实施，保留五项底栏、手机自然滚动、中英双语与既有授权边界。各批独立验证，未完成事项不记为已交付。

## 第一批：基础样式与页面状态（已完成）

- 统一正文、辅助文字、输入控件、上传入口、按钮分组和键盘焦点。
- 网站手机列表保留 TLS；计划任务保留下次执行时间与最近结果；主机服务保留运行状态。隐藏各列表的次要列。
- 空集合不复用无权限说明；读取错误先显示中文/英文摘要及下一步，原始错误在技术详情保留。
- 高级工具按分类筛选，并按可用高度与网格列数分页；未连接终端有明确引导。
- 中文变量字体拆分为常用子集与按需字符分包，保留全部原字体字符、许可和系统回退。
- 验证真实嵌入界面、手机布局、错误/空状态、上传入口、分页、字体请求和现有回归。

## 第二批：常用流程与详情

- 网站、软件、应用和数据库的常用表单采用业务字段，减少重复标题与通用参数信息。
- 创建流程检查依赖；默认值、资源标识与可选参数按实际 schema 处理，保留草稿、确认、版本与幂等机制。
- 网站 TLS、软件实例、数据库、文件和 MCP 详情统一层级；MCP 用途预设仍受当前授权限制。
- 补齐监控轴线、读数、时间范围及后端已有网络/负载数据；首页容量与数据时间。

## 第三批：功能补齐

- 环境诊断与版本维护入口。
- 授权范围内的网站、域名、应用和数据库资源搜索。
- 文件多选、排序、多文件上传队列，保留每项上传与冲突校验。
- 备份保留与清理策略、恢复核验记录，以及必要的监控告警。
- 浏览器客户端兼容检查、常用地址与下载/会话说明。

## 第四批：场景与发行验收

- 修正截图夹具的归档查询、安装/可用状态与分页；示例数据和真实生命周期证据分开标注。
- 主入口、资源详情、表单、任务、错误态、空态、无权限、长名称和大量资源。
- 中英 × 三套字体 × 五套配色；桌面/手机、键盘、文字放大、软键盘与断线恢复。
- 更新当前截图和说明。是否发行新 beta 按后续发行指令执行，不覆盖已有发行资产。

## 第一批验证记录

开发验证包：`1.0-beta7-ui-batch1`，本地 Linux amd64 构建；未创建新的公开 beta/tag，未修改安装器或主机业务动作。验证包包含未提交工作树，不能作为正式发行资产。

- TypeScript 与 Next.js 静态构建通过；前端 97 项测试通过。
- 实际嵌入界面的 30 组语言/字体/配色 × 五种尺寸回归通过，涵盖导航、分页、草稿与应用日志入口，页面脚本错误为零。
- 新增 `tests/rewrite/test_ui_polish_browser.py` 通过：手机网站与计划字段、真实空回收站、选择文件、执行器未配置/无权限错误、工具分页分类和终端初始状态。
- 默认中文界面首次字体传输从 8,132,696 字节降到 **558,636 字节**（约降低 93.1%，统计字体资源，不是整个页面流量或互联网性能基准）。
- Sans/Serif 各 16 个子集，分别覆盖原字体全部 30,890 / 30,928 个 cmap 字符，未丢失变量字重轴；完整源字体移到非公开资源目录，字体和字形按需加载，不引入外部字体服务。
- 运行验证使用 Chromium；手机实体设备、软键盘和全流程视觉验收继续属于第四批。
