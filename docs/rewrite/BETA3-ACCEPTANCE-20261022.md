# Folio 1.0-beta3 验收记录

日期：2026-10-22（Asia/Singapore）。本轮围绕备份总量限制与四项审计整改。

## 源码与功能回归

- Go 各包 race 回归；调度器修复后重新执行包含所有新用例的 race 测试。
- 前端类型检查与 84 项测试。
- 安装器 33 项测试（普通用户环境中 2 项 root-policy 用例跳过）。
- 嵌套 MySQL driver race 测试。
- 新增回归：HTTP 503 不通过就绪检查、配置路径与状态码、取消检查、
  非本地路径拒绝；数据库 4 GiB 以上写入/稀疏文件收据与下载偏移；
  计划任务真实后台成功/失败/取消、provider 重启恢复、重叠保护、
  错过执行策略，以及本地 SMTP TLS 失败通知去重。

## 本轮 Ubuntu 隔离系统测试

环境为已有 Ubuntu 24.04.5 amd64 OCI 派生 systemd 镜像的独立 QEMU overlay，
内核 6.8.0-147-generic，TCG、2 vCPU、2 GiB。
该镜像用于定向回归，不能代替干净官方镜像的完整冷安装矩阵。

- `TestQARootLargeWebsiteBackupRoundTrip`：通过；实际创建并恢复
  **2 GiB + 4096 字节**的网站文件，恢复后核对大小及尾部标识。
- 网站备份恢复的独立用户/组和私有 umask 权限回归：通过。
- 数据库 4 GiB 以上写入/元数据/偏移检查：通过；使用稀疏文件和生产写入器，
  不是 4 GiB 真实数据库 dump 服务验收。
- 真实 Unix socket 数据库导出、校验失败阻断：通过。
- 真实 HTTP 503、指定检查路径和取消检查：通过。

## 发行验证

发行流程对冻结源码执行前端生产构建、amd64 打包、
包内版本/提交/干净状态检查与实际包 smoke。
包 smoke 使用包内安装器验证独立 prefix 安装、重复安装、API/UI、卸载及保留数据。
原始摘要及包哈希随 beta3 发行资产提供，避免文档中的提交号自引用。

## 明确保留的边界

- beta2 受管运行时/应用主机证据只证明 beta2 的对应范围；本轮不把它们记为 beta3 全量重跑。
- Debian、ARM、真实 DNS 供应商、公开 CA 及 phpMyAdmin/pgAdmin 原生主机工作流没有本轮通过声明。
- RC15 的性能门槛、两种系统的完整安装组合和系统变更清单仍是历史未关闭项；
  本次 beta 发布不将它们改写为通过，也不宣称正式版全部验收完成。
