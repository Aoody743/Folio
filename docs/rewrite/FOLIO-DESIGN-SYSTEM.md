# Folio 统一界面规范

更新：2026-10-23。当前开发界面的视觉规范以本文为准；产品范围与导航规则继续遵循 [UI 信息重构](UI-INFORMATION-REFACTOR.md)。

## 基础与主题

基于 [Astryx 0.6.8](https://astryx.atmeta.com/docs/getting-started) 的 Neutral 主题定制 Folio，保留月白、深空、雾紫、松绿、暖砂五套配色和三套双语字体预设。

- 唯一组件主题源：`frontend/src/themes/folio.source.ts`，使用官方 `defineTheme` 及主题编译器；生成 CSS、JS 与类型文件，随静态面板提供。
- 语义颜色映射到当前配色变量，表面、文字、强调色、边框和反馈在所有模块一致。
- 样式层级：`reset → astryx-base → folio-legacy → astryx-theme → folio`。旧业务布局被明确隔离，不能再覆盖组件主题。新增公共排版写入 `frontend/src/app/folio.css`；主题组件外观写入主题源，避免各页重复定字号、圆角和按钮颜色。
- `npm run theme:build` 生成主题，`npm run theme:check` 检查提交的产物是否过期；正式 UI 构建自动编译主题。

## 排版、图标与容器

| 项目 | 桌面 | 手机 |
| --- | --- | --- |
| 正文 / 输入 | 15px | 16px |
| 页面标题 | 24px / 600 | 22px / 600 |
| 分区标题 | 18px / 600 | 18px / 600 |
| 常规按钮 | 14px / 500 | 15px / 500 |
| 辅助信息 | 13px | 13px |
| 主机指标 | 36px / 500 | 30px / 500 |
| 控件高度 | 40px | 44px |
| 主容器内距 | 20px | 16px |

主要间距使用 8 / 12 / 16 / 24px，宽屏指标间距可用 32px。卡片圆角 12px，控件 8px。减少粗体和装饰背景，重要数据保持正文对比度。代码与日志使用独立等宽字体。

图标使用 Lucide，通过 Astryx Icon 统一渲染，18 / 20px 为常用尺寸；保留必要操作文字，图标按钮必须有可访问名称。不能仅凭颜色传达状态。

## 共用组件与操作规则

- `SectionHeader`：图标、分区标题、操作区，已用于全部使用公共卡片页头的模块。页面标题与分区标题各司其职，不再重复放置标题图标。
- `ResourceTabs`：统一使用 Astryx TabList / Tab，支持方向键、Home / End、单一 Tab 焦点以及窄屏横向浏览。窄屏只滚动标签栏，不撑宽页面。
- `ResourceDrawer`：沿用现有独立资源页及草稿保护，统一返回按钮、资源类型、名称、状态和详情分组；保留原有区域可访问名称与 hash 路由。
- `ResourceMeta` / `.detail-grid`：紧凑的信息行，标签在前、内容在后。只读字段不再各自套大卡片；路径、长名称允许换行。
- 列表统一表头、行距、名称链接、状态、分页与空状态；手机保留已有重要业务列，桌面仍按可用高度分页，手机允许纵向下滑。
- 普通提示一句说明；原始错误、环境要求和使用帮助按需展开。执行失败、无权限、执行器未配置、未知状态继续分别呈现。
- 原有危险操作确认、版本校验、预览计划、幂等提交、任务进度和输入草稿保留。界面精简不能替代这些行为。

## 页面覆盖

| 页面组 | 本轮处理 |
| --- | --- |
| 登录、概览、全局搜索 | 公共字体 / 控件 / 空状态；首页 CPU、内存、磁盘图标和读数层级 |
| 网站、证书、DNS、保留站点 | 公共页头和标签；网站概况改紧凑元数据；创建、配置、日志、备份使用同一容器规范 |
| 软件、应用、可选浏览器 | 单层资源导航，移除应用内部第二层分类；分类图标；目录不可读时仍可打开已授权安装实例；点击已安装服务直接进入管理，来源验证移入来源详情 |
| 外部数据库、缓存、本机实例 | 保持资源区分与标准详情入口；共用列表、标签、元数据、表单和任务反馈 |
| 数据库 / PHP / Docker / FTP 等工具 | 共用页头、标签、动作表单、确认与详情排版，不扩大原有开放范围 |
| 文件、上传、编辑、历史、回收站 | 共用页头、输入、列表、分页、详情返回；保留批量与上传队列能力 |
| 监控、告警、终端、计划、通知 | 共用页头、表格、表单；告警说明折叠，主要操作加图标 |
| 活动、便签、审计 | 公共标题、状态、列表、卡片、编辑器和按钮规则 |
| 安全、外观、MCP、环境、高级工具 | 统一页头返回位置；安全 / 令牌分区补齐公共标题；次要连接说明折叠 |
| 面板浏览器 | 同一表面、字号与控件规范；图标历史工具、地址栏、标签和会话操作；尺寸 / 帮助按需展开；空闲时短暂画面读取失败最多重试两次，权限失败及不确定输入仍需显式恢复 |
| Firefox WASM | 启动和安装页统一；完整 Firefox 上游浏览器界面保留原生行为 |

软件页浏览器安装的新地址为 `#/software?page=browsers`。原 `page=applications&subgroup=browsers` 继续兼容。底栏的概览、网站、软件、文件、更多顺序与位置不变；手机顶栏仍只保留任务按钮，语言在设置中切换。
