# 静态交互演示

演示复用正式 Next 静态导出的全部页面，再单独注入 `frontend/demo/runtime.js` 与明确的演示数据。正式产品不导入演示脚本，不改变原来的认证、授权或业务接口。

构建前先生成当前前端及嵌入服务二进制，然后运行：

```sh
python3 scripts/rewrite/build-demo.py --binary /absolute/path/to/folio --output /absolute/path/to/site/dist
python3 -m http.server 4178 --bind 127.0.0.1 --directory /absolute/path/to/site/dist
FOLIO_DEMO_URL=http://127.0.0.1:4178 python3 tests/rewrite/test_static_demo_browser.py
FOLIO_DEMO_URL=http://127.0.0.1:4178 python3 tests/rewrite/test_resource_ui_browser.py
FOLIO_DEMO_URL=http://127.0.0.1:4178 python3 tests/rewrite/test_project_filters_browser.py
```

构建依赖 Python Playwright、Pillow，字体再生成依赖 `fonttools[woff]`。构建器从隔离服务读取公开能力描述与软件目录，复用截图展示数据，不导出真实主机数据、管理员密码或登录令牌。输出目录必须专用于本演示，因为重新构建会替换它。

支持新建网站及本地任务进度、软件变更计划、连接配置、文件编辑/小文件上传/下载、计划任务、告警、便签、假令牌以及主题、字体、语言和页面导航。修改保存在当前浏览器，可通过「演示数据 → 重置演示」恢复；请勿填写真实凭据或上传敏感内容。

终端只有几个模拟命令，面板浏览器使用样例画面，Firefox 页面为明确标注的独立窗口外观演示。不提供真实服务器执行、网络代理、WASM 引擎或外部数据库连接；未实现的高级动作返回明确的演示提示，不宣称成功。

本轮验证了真实界面的登录与缺字回退、新建网站确认及任务、刷新保留、文件编辑保存、模拟终端、浏览器标签与地址栏、12 个入口的桌面和两种手机宽度。所有模拟 API 都由页面内处理，浏览器没有发起真实服务 API 请求。部署沿用 Sites 当前的访问范围，不由构建脚本修改共享策略。

## 缺字符号修复

Astryx 的 FieldLabel 用 U+2219（`∙`）分隔字段名称和必填/可选信息。Inter 与 Noto Sans SC / Noto Serif SC 的源字体缺少此字形；在截图环境缺乏合适系统回退时显示成方框。中文字体分片没有删除这个字形，问题来自原字体覆盖和系统回退。

`Folio Symbols` 从已有开放许可 Source Sans 3 字体提取该字形，仅 1,056 字节，并作为三套预设的本地回退。它不替换必填提示、不修改认证行为，也不依赖外部字体服务。使用 `scripts/rewrite/subset-symbols.py` 可再生成；浏览器回归通过 CDP 检查实际使用的自带字体与渲染字形。

## 交互反馈修订

顶栏展示操作系统，任务与全局设置为具名图标按钮。网站与已安装服务共用项目卡片、状态点和图标规范，网站证书入口进入该网站的 TLS 配置。网站按实际字段识别 PHP、静态、代理或显式 Git 项目；不把安装了 Git 客户端等同于网站采用 Git 部署。证书图标表示配置状态，不代替有效性或公网健康检查。

软件库按分类提供横向卡片轨道，完整列表保留搜索与筛选；点击卡片仍进入标准详情页。外部数据库与缓存连接合并在“数据连接”下，旧链接继续可用。浏览器安装模式采用独立卡片，使用页自动适配可用视口，低频工具收在菜单。演示画面按会话实际尺寸生成，不联系目标网页。

文件列表以 50 项为服务端分页单位，使用紧凑行与内部滚动；“…”及右键打开同一个 Astryx 菜单，具体动作表单在本页对话框中保留原来的权限、变更确认与防重复提交逻辑。手机折叠部分元数据，仍可经文件工具查看。

项目类型现在直接展开为总览、静态、PHP、Git、代理；状态采用 Astryx 多选下拉框。`sites_list` 新增可选 `project_type` 和 `statuses`，在授权过滤后、分页前组合筛选，旧 `status` 参数继续兼容。文件路径、短搜索、回收站和更多菜单合并成一条工具栏，排序、全选及批量操作集中在更多菜单。

“更多”页采用分组磁贴，退出登录位于内容底部。全局名称设置新增可选 `server_name`，省略字段保持原值，空字符串恢复系统主机名；既有修订校验继续生效。系统状态额外读取 `/etc/os-release` 的发行版名称和 ID，不改变原有 `os` 含义。12 个 Simple Icons 发行版图标以离线、可随主题变色的单色 SVG 提供，来源和 CC0-1.0 许可在 `frontend/public/distro-logos/`。

首页按桌面左右两栏排布：左侧紧凑主机与网站/应用摘要，右侧展示最近更新的三条未归档便签，有写权限时直接进入编辑。`notes_list` 可选 `sort: updated_at` 忽略置顶优先，默认列表行为保持兼容；读写权限、草稿保护和版本冲突处理继续复用既有便签编辑器。更多页使用居中的等宽磁贴网格，图标与下方文字分别居中，退出登录位于网格下方。验证脚本：`tests/rewrite/test_overview_more_browser.py`。
