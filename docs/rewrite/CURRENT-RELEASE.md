# Folio 当前发行与验收入口

更新：2026-10-23（Asia/Singapore）。当前发行版为 **1.0-beta7**。
本文件统一描述当前版本；RC15、beta1、beta2、beta3、beta4 的检查点和旧计划保留为历史，
不会自动成为新版已验收声明。

## 版本与支持范围

- 发行：Linux amd64/arm64 预发布包、amd64 一键脚本 `install-1.0-beta7.sh`、SHA-256 清单。
- 受管应用的目标平台延续 beta2：Ubuntu 24.04 amd64 + systemd。
- Debian/ARM 不因能够编译或目录有条目而自动列入当前已验收平台。
- beta2 运行时修复已合并，主线新增 phpMyAdmin/pgAdmin 适配器也保留。
  两个工具目前声明的 Debian 主机生命周期仍未验收，不属于支持矩阵。
- 真实 DNS provider/公开 CA 验收沿用此前延期决定；本地协议证据与外部验证分开记录。

## beta7 可选浏览器应用与导航修复

- “软件 → 应用服务 → 浏览器应用”提供面板 Chromium 与完整 Firefox WASM 两种可选模式，默认均不安装，安装状态相互独立。
- Firefox WASM 使用本服务器的认证 Wisp 出口；默认公共代理与外部字体请求已移除。需要 HTTPS 和 JSPI，完整 Firefox 控件使用上游语言。
- 安装与卸载使用可追踪任务、固定版本和 SHA-256 校验；卸载关闭所属连接并移除下载组件，保留另一模式与系统浏览器。
- Chromium 可复用系统安装，Linux amd64 缺少引擎时下载独立 headless shell 并检查沙箱；arm64 需先安装系统 Chromium。
- [双模式说明](SERVER-BROWSER.md) · [本轮验收](BROWSER-APPS-BETA7.md) · [发行证据](evidence/beta7-20261023/ACCEPTANCE.json)。
- 修复 Next 对 hash 历史记录的异步覆盖，快速切页、浏览器返回与直接链接保持正确。
- beta5、beta6 保留为准备期标签，未发布公开资产；本轮统一发行 beta7，已发布 beta4 资产保持不变。

## 沿用 beta3 的四项审计整改

| 项目 | 当前行为 | 验收 |
| --- | --- | --- |
| 应用启动检查 | 默认 2xx/3xx 才通过，5xx 重试至超时并停止失败服务；可配置回环路径、200–499 预期状态码、1–300 秒等待 | 真实 HTTP 成功/503/取消/路径限制回归 |
| 数据库定时备份 | `managed_database_backup` 加入受信任定时动作，网页/REST/MCP 使用同一动作表和权限 | 动作注册及调度/任务回归 |
| 计划任务最终状态 | 记录 task_id 与发起身份，以当前权限读取任务；回写成功、失败、取消、中断；重启后继续核对 | 持久化恢复、取消、重叠、错过执行、SMTP TLS 通知回归 |
| 验收追溯 | 本文件为当前入口，历史计划明确标注版本边界，发行包 BUILDINFO 绑定冻结提交 | 发布说明、安装器、源码与包检查 |

网站备份/恢复取消 2 GiB 总量限制；数据库备份取消 4 GiB 总量限制；
网站/数据库受控下载和范围偏移也不再限制总备份大小。
处理保持流式、有校验、可取消，不把整个备份装入内存。
本次不改变单次 MCP JSON 分块、外部导入解析器、操作时限或路径/权限边界。

## 计划任务策略

- `overlap_policy`：默认 `skip`；`allow` 可显式允许并发。手动触发受默认重叠保护。
- `misfire_policy`：默认 `run_once`，多次错过只补一次；`skip` 跳过超过
  `misfire_grace_seconds` 的一次过期触发。默认宽限 60 秒。
- `failure_channel_id`：可选 SMTP/Telegram 渠道，设置及发送均检查当前授权。
- 任务结果读取需要 `tasks:read` 和对应资源权限。失去权限时显示
  `observation_denied`，不会把未知结果当成功。
- 通知先持久化发送声明，再提交通知任务，避免进程恢复后重复发送。
  发送中崩溃的声明保留供检查；“通知已提交”不代表收件人已收到。
- 默认没有自动重试可能已经改变主机的失败操作；用户检查结果后可以手动重跑。
