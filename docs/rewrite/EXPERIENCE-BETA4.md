# Folio beta4：安装引导与双语界面

本轮围绕“安装后能顺利进入面板，提交操作后知道结果与下一步”完善体验。

## 中英文

- 面板首次使用按浏览器语言选择中文或英文；登录前后都可切换，偏好保存在当前浏览器。
- 切换时更新 HTML 语言、日期格式与组件库提示，不重载页面，不清空表单或改变当前操作。
- 应用文案使用 `frontend/src/lib/i18n.ts` 与 `messages.en.ts`。资源名称、便签、文件、SQL、命令及原始日志保持原文；服务器返回的外部诊断文本保留原始证据。
- 静态标签表在读取时翻译，避免切换后只更新部分导航。参数用占位符插值，不翻译用户数据。
- CI 检查翻译覆盖、占位符一致性、存储不可用时的切换与现有标签表的动态更新。

## 安装向导

新版本入口 `install-1.0-beta4.sh`；既有版本入口保持不变。核心安装器仍使用原有校验、锁、快照和恢复流程。

```sh
# 中文；英文使用 --lang en
bash install-1.0-beta4.sh --lang zh-CN
# 自动化：不等待终端输入
bash install-1.0-beta4.sh --lang en --yes --no-color
```

没有显式语言选择时参考 `FOLIO_LANG` / 系统 locale；交互终端可先选择语言。提供六个真实阶段、终端下载进度与阶段耗时、首次安装/升级说明、配置摘要，以及访问与初始化交接。`--prefix` 会说明需要手动启动；不会宣称服务已经通过生产健康检查。

交互确认使用 `/dev/tty`，不读取管道中的脚本；无人值守不等待回答。拒绝确认时安装目录不发生变更。安装摘要文件权限为 0600，只记录展示文案，不复制环境变量、策略、密码、初始化令牌或命令参数。故障时保留恢复现场，API 恢复与 Agent 需单独恢复的状态分别报告。

修改安装器展示代码或中文文案后执行：

```sh
python3 scripts/rewrite/sync-installer-ui.py
python3 scripts/rewrite/sync-installer-ui.py --check
```

生成结果嵌入核心安装器和新版入口，发行包继续自包含；无需运行时下载语言包。

## 界面

- 保留五项底部导航与五套主题，统一双语字号、换行、焦点与状态语义。
- 网站初始设置改为可展开引导，提供推荐理由、稍后设置与继续设置；更换运行栈的说明放在选择步骤内。
- 收紧首页空便签、空任务、空事件卡片；手机首屏不再为每个空状态预留大块空间。
- 软件变更确认展示结构化版本、目标、软件包、配置和影响内容；原始计划折叠展示，敏感字段脱敏。
- 任务详情共用阶段与结果组件。阶段只跟随服务器实际状态，不从百分比推断验证成功；状态读取失败和执行失败分别提示。
- 任务结果默认折叠；保留日志读取、取消与恢复入口。最近任务也使用同一详情。
- 软件和动作搜索支持译文；全局搜索动作会进入对应操作表单，并保留返回入口。
- 沿用已有专用表单、草稿保护与手机全屏抽屉，在同一套交互基础上改进高频路径。

## 验证范围

前端单元测试、类型检查、静态构建；安装器安全与事务回归；终端确认和管道安装；真实发行包启动；真实 Chromium 中英文切换、输入保留、用户内容原文、语言持久化、四种宽度与五套主题；隔离 systemd 主机上的升级及健康检查。

本轮不新增业务模块，也不改变 REST/MCP 动作、权限或服务端数据格式。
