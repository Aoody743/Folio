# Folio 1.0-beta7 面板完整截图

本索引收录当前 beta7 的面板页面、常用手机布局及两种浏览器模式，共 40 张截图：31 张面板桌面页面、6 张面板手机页面和 3 张浏览器模式页面。

面板截图由 beta7 可执行文件在隔离的本地演示环境中生成。主机数据、网站、应用、文件、任务、便签和操作记录均为展示夹具，不代表真实服务器状态；软件库显示随程序内置的目录。截图不会执行管理操作。浏览器模式截图使用实际面板浏览器，Firefox WASM 中的 Open Atlas 为本机演示站点。
