Folio modifications to the upstream demo bootstrap and HTML:
- Remove external Google Fonts and the Puter public Wisp endpoint lookup.
- Force authenticated, same-origin Folio Wisp with a CSRF WebSocket subprotocol.
- Scope saved launch preferences and local profiles by identity; start with a blank page.
- Add bilingual launch controls, compatibility checks and return/fullscreen controls.
- Reserve space above the Firefox canvas for Folio navigation.
The complete human-readable modification source is internal/serverbrowser/wasm.go
in the corresponding Folio release source, https://github.com/Aoody743/Folio.
No Firefox WASM engine binary is modified. Source for covered files, including
upstream build instructions and the changes above, is available at these URLs.

The separately optional Chrome for Testing headless shell retains its upstream
ABOUT and LICENSE.headless_shell files inside the downloaded app directory.
